# Privacy, provenance, licences and release

**2026-10-21.** Public Git is for contracts, original synthetic examples, documentation and redistributable source only.

## Asset categories and boundaries

- **Historical 7VST recordings, source WAVs, MP3s, MP4s, Bidule/Vuo sessions and original score material:** privately held and hash-preserved by their owning project, never copied into sing automatically.
- **Aeschylus classical dramatic source vs. a modern translated text:** the ancient work and the specific English translation have different rights; the private restoration records a University of Chicago notice, not a confirmed translator or publication grant.
- **Plogue Alter/Ego signed binaries and Marie Ork, Daisy or Bones voice material:** external licensed dependencies, not Fountain Coach redistributable assets; voice performer and sample-bank credits must be retained. Follow the original bank distribution terms.
- **Contexter/Chormusik code:** inspect as predecessor, but audit its own and any vendored licenses before porting source. This repository's public visibility alone does not grant a compatible licence.
- **New voice recordings:** informed consent for recording, transformation/training, identity, use and withdrawal terms; do not create impersonation voices without permission.
- **Model-assisted takes:** separate grant, paid-provider permissions if any, training/embedding and redistribution permissions; private candidates are not releases.

## Production boundary

An instrument generates sound. Satzfunk manages candidate editions and author approval. EstatePublisher is independently authorized to publish immutable reviewed deliverables. Git commit, HTTP preview and local generated audio are not public release authority.

Record who owns the source, who performs, whose voice bank/model is used, which renderer built output, the exact edit and consent scope, and the original/derived relationship. A child inherits **references**, never automatically inherits licences or access.

## Security and operational care

No plain-text account keys or Apple Keychain exports, no external text leaks, no vendor bank copies, no disabling code signing, no unbounded autonomous deployment, no GitHub CI. Mac local testing and Linux private previews remain distinct; don't compile on Hetzner as a shortcut. Prefer local tests and versioned source receipts; publish only after rights review.
